scada-schema

Wind and PV SCADA data arrive in as many layouts as there are operators: columns named after a vendor's tag list, power in hectowatts or watts, time in local time or at the end of the interval, a status code that only the manual explains. This project fixes one schema, reads open datasets into it from their original files, checks the data, maps the status codes to IEC 61400-26 categories and hands the table to wind-up, OpenOA and pvlib, with a check that the tools give the same result either way. IEC 61400-26 mapping

The code tables translate a controller's status codes into the ten information categories. Where the operator also labels every stop, the table can be compared with the label (the Senvion table was written from the same logs, so that is a consistency check).

Converters and parity

The same source file goes into the target tool twice: through this library and by hand with plain pandas and the tool's own column names. The tool's own functions then run on both inputs.
