# Changelog

## Unreleased

Generic importer driven by a YAML mapping (`scada-schema import`), JSON Schema files and a column list (`scada-schema jsonschema`).

## 0.1.0

First version: the schema (wind and PV profiles, version 1.0), loaders for Kelmarsh, Penmanshiel, Hill of Towie, CARE to Compare
and NREL PVDAQ, 15 quality checks with an HTML report, IEC 61400-26 state mapping, converters to wind-up, OpenOA and pvlib with
parity checks, a command line interface and the study that produces every number of the README.
